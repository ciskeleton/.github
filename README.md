# CiSkeleton Community Health Files

This repository contains shared files and configuration used across the CiSkeleton GitHub organization.

It includes:

* Organization profile content
* Default issue templates
* Pull request templates
* Community health files
* Shared GitHub workflows
* Funding configuration
* Other organization-wide settings

The public organization profile is available at:
